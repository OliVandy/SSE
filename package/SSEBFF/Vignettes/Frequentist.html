Sample Size Estimation for Clinical Trials in Multiple Paradigms-Frequentist

Rachel Zhuang and R. Oliver VandenBerg

2025-06-30

The SSEBFF package is designed to assist in sample size estimation for clinical trials across various paradigms, including Frequentist and Bayesian. This vignette focuses on the Frequentist paradigm.

Introduction

Sample size estimation is a critical step in the design of clinical trials. The SSEBFF package provides tools for estimating sample sizes in Frequentist clinical trial designs.

In Frequentist paradigms, sample size estimation typically involves determining the number of participants needed to achieve a specified level of statistical power, given a hypothesized effect size and significance level. The package includes functions that allow users to perform these calculations for various types of clinical trials, including those with binary and continuous outcomes.

One-arm trial means we are testing a single treatment against a null hypothesis. Two-arm trial means we are comparing two treatments, like a new drug against a control treatment.

We are doing a one-sided test, which means we are only interested in detecting an effect in one direction (e.g., the new treatment is better than the control). The hypothesis testing framework used in frequentist paradigms relies on the concept of null and alternative hypotheses. In one-arm practicing, the null hypothesis typically states that the treatment has no effect \((H_0: \theta \le \theta^*)\), where \(\theta^*\) is the threshold and is also depicted as \(\theta_0\) or margin), while the alternative hypothesis posits that the treatment does have an effect. \((H_a: \theta > \theta^*)\) The sample size is calculated to ensure that the trial has sufficient power to detect a true effect if it exists. While in two-arm, the null hypothesis states that there is no difference between the two treatment groups \((H_0: \theta_T \le \theta_C)\), where \(\theta_T\) is the treatment group parameter, and \(\theta_C\) is the control group parameter), and the alternative hypothesis states that there is a difference \((H_a: \theta_T > \theta_C)\), or \((H_a: \theta_T - \theta_C > \theta^*)\)).

library(SSEBFF)

We will demonstrate the package function through example simulations. In this package we provide a combined function for sample size estimation for both one-arm and two-arm trials, which can be used to estimate the sample size needed to achieve a specified power and significance level.

Example: Binary Sample Size Estimation for One-Arm and Two-Arm Trials

Scenario: We want to estimate the sample size needed to detect a difference in proportions between right-handed and left-handed individuals.

\(\alpha\) is the significance level, which is the probability of rejecting the null hypothesis when it is true (Type I error). \(\beta\) is the power of the test, which is the probability of correctly rejecting the null hypothesis when it is false (1 - Type II error). The higher the power, the more likely we are to detect a true effect if it exists.

Freq_Binary_theoretical(alpha = 0.05, beta = 0.2, theta1 = 0.9, theta0 = 0.2)
## [1] 4
# theta1 is the expected proportion of right-handed individuals, and theta0 is the expected proportion of left-handed individuals.

We could also use the package to estimate sample size for continuous outcomes. t_test_sim_sample_size is a function that estimates the sample size needed for a t-test in both one-arm and two-arm trials, and it uses the Monte Carlo simulation.

Example: Continuous Sample Size Estimation for One-Arm and Two-Arm Trials Using T-test

Scenario: We want to estimate the sample size needed to detect a difference in means between male height and female height.

t_test_sim_sample_size(alpha = 0.05, beta = 0.2, mu1 = 174, mu0 = 163,
                       sigma1 = 6.5, sigma0 = 6,
                       type = "two.sample",
                       nmin = 10, nmax = 5000, sims = 10000)
## [1] 10
# mu1 is the expected mean height for male, and mu0 is the expected mean height for female. Sigma1 is the standard deviation of collected male height data, and sigma0 is the standard deviation of collected female height data.

Freq_Count_Combined

This function is designed to estimate the sample size needed for a one-arm or two-arm trial with count data. This function can be used to determine the required sample size based on the expected event rates and the desired power and significance level.

For example, we are comparing shot success between two basketball players. Player A hits 12 shots/game on average, and Player B hits 8 shots/game. We want to know: how many games should you record to be 95% sure that Player A’s scoring rate is really higher than Player B’s — and not just random luck?

Freq_Count_Combined(
  alpha = 0.05,
  beta = 0.1,
  mu1 = 12,    # Player A's shot rate
  mu0 = 8,     # Player B's shot rate
  sig1 = 2,    # Standard deviation of Player A's shot rate
  sig0 = 1.5,  # Standard deviation of Player B's shot rate
  type = "two.sample",
  nmin = 5,
  nmax = 300,
  sims = 100
)
## $n_theory
## [1] 11
## 
## $n_sim
## [1] 66

Conclusion

The SSEBFF package provides a comprehensive set of tools for sample size estimation in frequentist clinical trials. By using the functions provided, researchers can easily calculate the required sample sizes and posterior probability for both one-arm and two-arm trials, ensuring that their studies are adequately powered to detect meaningful effects.
